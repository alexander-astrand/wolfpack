# Decisions

The kit's own decisions and why, one short file each, numbered in the order they were made. Write one when the decision is made, not later. A decision that changes gets a new file that says it replaces the old one; the old one stays. Decisions made before kit 1.6 live in the project that made them (Hutzup's `docs/decisions/`, 0009 for full auto).

Each file has: **Status** (accepted, or replaced by NNNN), **Context** (what forced the choice), **Decision** (what we chose, plainly), **Consequences** (what it costs and what it makes easy).
