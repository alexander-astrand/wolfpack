# Decisions

What we decided and why, one short file each, numbered in the order they were made (`0001-start.md`, `0002-<topic>.md`). Write one when the decision is made, not later. A decision that changes gets a new file that says it replaces the old one; the old one stays.

Each file has: **Status** (accepted, or replaced by NNNN), **Context** (what forced the choice), **Decision** (what we chose, plainly), **Consequences** (what it costs and what it makes easy).
