# Design library (template)

The library is each project's own, so the plugin ships only this empty template. Copy it to `~/.claude/plans/design/library.md` before the first `/superlab` round; the skill, the `heisenberg` agent and `mosbius-designs` read it there.

What goes in it: every brief, gallery and pick, with why. `/superlab` and `heisenberg` read it before writing a brief, and record each pick here against `heisenberg`'s lean, so the studio learns where Alexander's taste differs from the director's. A declined leap gets a row too. `/jedi-council` reviews the record.

One row per page per round. Alexander's words go in verbatim, in quotes, dated. `Score` is how his pick went once built: kept / sent back / overturned (blank until known; `/memento` and `/superlab` step 8 fill it, and `heisenberg.md`'s `## Leans` is rewritten from it).
